## From a dice game to a shared place

I began with Las Vegas and gradually asked for a tavern around it: characters, chairs, games, meals and a recipe book. My central question became whether friends could understand what to do together without me explaining the interface. Gather supplied a spatial reference; Red Dead Redemption 2 and Stardew Valley supplied atmosphere. These references shaped the product, but did not establish that my version worked. I repeatedly used screenshots and playtests to reject results that looked acceptable to an agent. The project’s argument is now in README; the operational instructions belong in the handbook rather than an ever-growing front page.

The scope grew further than the original single game. Poker, dominoes and Blackjack offer different shared activities, while recipes give the counter a practical purpose beyond the game. That expansion also made consistency expensive: “leave” and “away” had to mean the same thing across separate engines. The latest lifecycle corrections, rather than the number of games, are the better evidence of progress ([2e5f10a](https://github.com/comp4020-agentic-coding-studio/comp4020-final-shuyangyuzu-cmd/commit/2e5f10a)).

## Stack and agent workflow

The deployed stack is TypeScript/Node, Hono HTTP routes, SQLite, and browser JavaScript with canvas and CSS. SQLite fits the course’s single-machine persistent-volume model and keeps transactions close to the game rules. It also concentrates writes and creates a deployment constraint: treating multiple independent machines as interchangeable would require a different storage design. Canvas gives control over the tavern, but makes geometry and visual acceptance harder than ordinary document layout. The book and account forms therefore use browser elements where focus, text and buttons matter.

I used Claude and Codex for implementation, diagnosis and independent review. Their roles were not interchangeable with mine: agents could check state and run scripts; I supplied the intended experience and rejected mismatches. Worktrees allowed separate work, but made explicit handoffs necessary. A clean merge alone did not prove that eating locks and game actions agreed. The preserved review and corrections document that boundary ([3b3b754](https://github.com/comp4020-agentic-coding-studio/comp4020-final-shuyangyuzu-cmd/commit/3b3b754)).

My workflow became smaller changes, recorded evidence, and explicit review before release. Local tests needed a fresh data directory, a known port, and the actual listening Windows PID. Earlier background-process handling confused wrapper PIDs with servers. That made claims about “fresh” runs unreliable. The lesson was to verify the environment as well as the code, and to preserve uncertainty when a prior failure could no longer be reproduced.

## Corrections that changed the harness

The menu was initially a popup with pagination, not the physical book I meant. Later versions turned pages but visibly enlarged or hesitated. I clarified that growing and unfolding belonged to opening the book, not every page turn. This was a product judgement a green suite could not supply. Claude’s later cover redesign also uncovered a mobile contents page that existed in code but was never reachable. The correction and real-browser checks are recorded in [ae6a7ec](https://github.com/comp4020-agentic-coding-studio/comp4020-final-shuyangyuzu-cmd/commit/ae6a7ec).

Eating revealed the same distinction. A visible canvas was insufficient: utensils missed the mouth, and food later reappeared on an emptied plate. I reported those defects through screenshots and direct viewing. The final food-state fix separates consumption from the plate’s lowering movement and tests that consumption never reverses ([2e5f10a](https://github.com/comp4020-agentic-coding-studio/comp4020-final-shuyangyuzu-cmd/commit/2e5f10a)). That is stronger than merely retrying a screenshot until it looks right. The latest animation still needs my final confirmation; the record must not convert a fix into an acceptance I did not give.

Multiplayer checking also needed the second browser’s rendered view. Server-side assertions missed Blackjack’s away flag because the client redrew only when the game version changed. Claude added a separate presence signature and rechecked two browser contexts ([ae6a7ec](https://github.com/comp4020-agentic-coding-studio/comp4020-final-shuyangyuzu-cmd/commit/ae6a7ec)). This supports a narrower claim than “all multiplayer works”: the recorded scenarios passed, while new interaction sequences still need scrutiny.

## Tests, ownership and limits

A recurring suite failure was initially dismissed as pre-existing contention. Investigation found an actual voice-test resource leak as well as concurrent competition for shared fixtures. Cleanup and serial test-file execution addressed those mechanisms ([26454f0](https://github.com/comp4020-agentic-coding-studio/comp4020-final-shuyangyuzu-cmd/commit/26454f0)). A later eating test compared two millisecond timestamps and could fail even when the second action was correctly recorded; Codex replaced that assumption with the persisted request identity ([f37ae29](https://github.com/comp4020-agentic-coding-studio/comp4020-final-shuyangyuzu-cmd/commit/f37ae29)). An isolated passing test is not proof that every intermittent full-suite failure is harmless.

Community recipes required account ownership, private drafts, image handling and stable shopping plans, not just a public form. Codex implemented recipe snapshots so an author’s later edit cannot silently alter someone else’s plan ([c6d105d](https://github.com/comp4020-agentic-coding-studio/comp4020-final-shuyangyuzu-cmd/commit/c6d105d)). Claude extended the model to food while preserving existing drinks and unit-aware quantities ([0105851](https://github.com/comp4020-agentic-coding-studio/comp4020-final-shuyangyuzu-cmd/commit/0105851)). The photo-composer correction then proved why actual pointer interaction matters: mobile controls covered almost the entire draggable image ([1926aac](https://github.com/comp4020-agentic-coding-studio/comp4020-final-shuyangyuzu-cmd/commit/1926aac)).

I withdrew voice calling after my friend and I still could not reliably hear one another. Signalling fixes, synthetic audio and local relay tests were useful engineering evidence, but did not fulfil the real-device promise. Its entry points are hidden; the implementation remains for traceability. This is a scope decision, not a successful audio feature disguised as a limitation.
